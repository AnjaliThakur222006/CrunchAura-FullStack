# Angular Syllabus Mapping

This project uses syllabus concepts naturally inside a real website.

| Concept | Real project use |
|---|---|
| Standalone Components | All Angular pages/components |
| Routing | Public/auth/dashboard navigation |
| Lazy Loading | Customer dashboard feature |
| TypeScript interfaces | Product/User/Order models |
| Services | API/Auth/Cart services |
| Dependency Injection | Services injected into components |
| HttpClient | Django REST calls |
| Observables/RxJS | API streams and cart/product streams |
| Signals | Cart count, login state, UI state |
| Data Binding | Product and form UI |
| Reactive Forms | Login/Register/Profile/Contact |
| FormArray | Registration preferences / future bulk items |
| Validators | Email/password/required fields |
| Route Guard | Dashboard authentication |
| Custom Directive | Product/new badge highlight |
| Custom Pipe | Product name shortening |
| ngClass | Product status/category classes |
| CurrencyPipe | Prices |
| Error Handling | API error messages |
| Environment | Dev/prod API URLs |

The project prioritizes real product requirements over artificial examples.
