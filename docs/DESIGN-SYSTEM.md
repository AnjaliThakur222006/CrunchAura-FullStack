# CrunchAura Design System

## Brand colors

Primary:
- Forest 950: `#0C3C2E`
- Forest 900: `#103F31`
- Forest 800: `#185743`
- Forest 700: `#246B53`

Surfaces:
- Ivory: `#FDFBF7`
- Warm White: `#FFFDF8`
- Soft Sand: `#F3EBDD`

Accent:
- Muted Gold: `#C8A85B`
- Gold Dark: `#9D7A35`

Text:
- Ink: `#17211D`
- Muted: `#66716B`

Status:
- Success: `#2D7A56`
- Danger: `#B34A43`

## Typography

Display:
- `Cormorant Garamond` — large hero/editorial headings

Body:
- `DM Sans` — navigation, body, forms, buttons

Rule:
- Use display font for H1/H2 and major brand storytelling.
- Use DM Sans for normal content.
- Do not use more than two font families.

## Sizes

Desktop:
- H1: 56–72px
- H2: 38–48px
- H3: 22–28px
- body: 16px
- small: 13–14px

Mobile:
- H1: 40–48px
- H2: 30–36px
- body: 15–16px

## UI rules

Buttons:
- 10–14px vertical padding
- rounded 999px for primary CTA
- use gold for important action
- use green for secondary/brand action

Cards:
- 16–24px radius
- very soft shadow
- 1px border on light surfaces

Animation:
- 180–300ms
- translate/opacity preferred
- no constant bouncing

## Image rules

Hero:
- wide 16:9 or 4:3 food/packaging image
- subject on right, copy on left

Product:
- 1:1 crop
- package centered
- neutral/ivory background

About:
- 4:3 origin/process photography

Use `loading="lazy"` for below-the-fold images.

## Layout

Max content width: 1180–1240px.
Desktop side padding: 32px.
Mobile side padding: 18px.
Use CSS Grid/Flex; avoid fixed widths.
