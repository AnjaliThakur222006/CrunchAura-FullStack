# CrunchAura User Flows

## Visitor → Product → Cart → Order

Home
→ Shop
→ Filter/Search
→ Product Detail
→ Add to Cart
→ Cart drawer/page
→ Login/Register if required
→ Create Order
→ Order Confirmation
→ Dashboard / Orders

## Visitor → B2B

Home
→ B2B Export
→ Read export proposition
→ Submit enquiry
→ API saves enquiry
→ Admin follows up

## Customer → Feedback

Login
→ Dashboard
→ Feedback
→ Create
→ API POST
→ Feedback list refreshes through Observable
→ Edit/Delete own feedback

## Customer → Profile

Login
→ Dashboard
→ Profile
→ Edit fields
→ Validation
→ Save
→ API PUT
→ Success message

## Admin

Admin login
→ Django Admin
→ Products / Orders / Feedback / B2B Enquiries / Users
→ Review and update records
